## Setting them

::code-group
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['boneprint/nuxt'],
  boneprint: {
    reveal: 'sequence',
  },
})
```

```ts [main.ts (Vue)]
import { boneprint } from 'boneprint'

app.use(boneprint, { reveal: 'sequence' })
```
::

| Option | Default | Purpose |
| --- | --- | --- |
| `persist` | `true` | remember shapes between visits |
| `debug` | `false` | outline every skeleton and report whether the page moved, see [Debugging](/docs/guide/debugging) |
| `reveal` | `fade` | how content replaces the skeleton: `fade`, `sequence` or `sweep` |

`persist` and `reveal` can also be set on one skeleton as props.

## forgetSkeletons()

Clears the remembered shapes. Whatever is on screen won't be written back, even as it unmounts. Call it on sign-out.

```ts
forgetSkeletons()
```

Auto-imported in Nuxt. In Vue, `import { forgetSkeletons } from 'boneprint'`, or add it to auto-imports as shown in [Vue + Vite](/docs/getting-started/vue#auto-import).

## Entry points

| Import | For |
| --- | --- |
| `boneprint/nuxt` | the Nuxt module |
| `boneprint` | Vue: the components, `forgetSkeletons` and the `boneprint` plugin |
| `boneprint/resolver` | `boneprintResolver()` for `unplugin-vue-components` |

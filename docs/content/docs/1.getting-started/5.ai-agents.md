## A prompt that works

```md
Add boneprint to this app (docs: https://kukson777.github.io/boneprint/llms-full.txt).
Wrap the list in <file> in <Skeleton :of="..."> with a sample of typical text length,
add #empty and #error slots, and skip requests inside the slot where useInSkeleton() is true.
```

## The cheat sheet

- **Install:** `npm install boneprint`. Nuxt: `modules: ['boneprint/nuxt']`, everything auto-imported. Vue: `import { Skeleton } from 'boneprint'`, or `app.use(boneprint, options)`.
- **Wrap:** `<Skeleton :of="request" :sample>` with `#default="{ data }"`, `#empty` and `#error="{ error }"`. `request` is a `useFetch`, `useAsyncData` or TanStack Query result.
- **By hand:** `:data`, `:loading`, `:empty`, `:error` instead of or on top of `:of`.
- **Sample:** mirrors the response, with text of typical length. It only draws the first visit, after that the remembered shape is used.
- **Memory:** kept per `id`. Set one on a skeleton inside tabs or anything else that remounts; `forgetSkeletons()` on sign-out.
- **Slot runs twice:** once measured, once as content. Fetch outside `<Skeleton>`, or skip it where `useInSkeleton()` is `true`.
- **Steer:** `data-skeleton-block` (one block), `data-skeleton-skip` (left out), `#skeleton` slot with `<SkeletonBox>` for charts and canvases.
- **Style:** `--skeleton-*` CSS variables, see [Theming](/docs/customization/theming).

An ordinary skeleton has to be built twice: you repeat the card in gray rectangles and keep both versions in sync. Change the card, and the loading state no longer matches it.

Boneprint uses the markup you already have. It lays that markup out invisibly with sample data, measures where each line of text and each image lands, and draws bones on top.

What that gives you:

- a bar for every line of text and a block for every image, button and chip;
- a skeleton that shows up before JavaScript loads when rendering on the server;
- a remembered shape on reload, so blocks are the right size from the first paint;
- `<Skeleton :of="useFetch(...)">`, or a TanStack Query result, handles loading, empty responses and errors for you.

It works in Nuxt 3 and 4 as a module and in Vue 3 with Vite as a plugin: see [Nuxt module](/docs/getting-started/nuxt) or [Vue + Vite](/docs/getting-started/vue) to install it. See it live on the [home page](/). The approach is inspired by [skullet](https://github.com/lochie/skullet).

## Install

::code-group
```bash [npm]
npm install boneprint
```

```bash [pnpm]
pnpm add boneprint
```

```bash [yarn]
yarn add boneprint
```

```bash [bun]
bun add boneprint
```
::

Then add the module:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['boneprint/nuxt'],
})
```

That's all. `<Skeleton>`, `<SkeletonBox>`, `<SkeletonSuspense>` and `forgetSkeletons()` are auto-imported, and the styles are added for you. Works with Nuxt 3 and Nuxt 4.

## Options

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['boneprint/nuxt'],
  boneprint: {
    reveal: 'sequence',
  },
})
```

Every option is listed on the [Options](/docs/api/options) page.

## What you get with server rendering

The server sends the skeleton in the HTML, and a small inline script draws a remembered shape before the app loads. So even before JavaScript runs, blocks are the size the content will be. Next: [Quick Start](/docs/getting-started/quick-start).
